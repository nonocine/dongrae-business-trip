# 직인사용대장 증서 PDF — 긴 글자 자동 맞춤 결과

`npm run test:seal-cert -- --shots` 로 만든 화면입니다(pdf.js 로 그린 실제 PDF). `preview-*` 는 미리보기(직인 없음), `issued-*` 는 발급본(직인 자리는 시험용 검은 도형)입니다.

| 번호 | 시험 내용 | 결과 |
|---|---|---|
| 01 | 행사명 15자 · 단체명 20자 | 둘 다 원래 크기(14pt) 한 줄 |
| 02 | 행사명 30자 · 단체명 20자 | 둘 다 원래 크기(14pt) 한 줄 |
| 03 | 행사명 60자(띄어쓰기 있음) | 70%(9.8pt)로 줄여도 넘쳐 어절 단위 2줄 |
| 04 | 행사명 60자 · 단체명 20자(둘 다 띄어쓰기 없음) | 행사명 70% 글자 단위 2줄, 단체명 14pt 한 줄 |
| 05 | 제목 20자 · 외국인 이름 47자 | 제목 2줄(가운데), 이름 14pt 한 줄 |
| 06 | 한도 끝(항목 8개 · 항목 이름 20자 · 값 60자 · 본문 1000자) | 70%로도 안 들어가 더 줄임 — 그래도 모든 글자가 테두리 안 |

자동 검사(같은 스크립트): 모든 글자가 테두리 안 · 글자끼리 겹침 없음 · 넣은 글자를 하나도 버리지 않음 · 15/30/60자 행사명과 20자 단체명은 원래 크기의 70% 이상 · 미리보기와 발급본 배치가 같음.
(06 은 바꾸기 전 코드에서 본문이 아래 테두리를 넘어 실패하던 경우입니다.)
